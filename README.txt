SweetdreamsbyMily – IT371 M2.4

This is a one-page website. Open index.html in a browser.

EDITING THE GALLERY
1. Put a new photo in the images folder.
2. Open index.html in a text editor.
3. In the Gallery section, change the filename inside src="images/...".
4. Change the figcaption text if desired.
5. Save index.html and refresh the browser.

The gallery currently includes the event photos supplied for this project.
The logo/banner is displayed at the top of the Home section.
The business-card image is stored in images/business-card.png so it can be added later if desired.
